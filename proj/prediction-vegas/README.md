# prediction-vegas
Using Machine Learning through Keras and TensorFlow to predict the performance of NFL players in their upcoming games.
Currently only works with Wide Receivers (relevant ones at that)
On the website input as directed
Anything above 100 for a preferability score should be considered to place a bet


run this for the website to work as of now : cd backend  |then|  python -m uvicorn main:app --reload
